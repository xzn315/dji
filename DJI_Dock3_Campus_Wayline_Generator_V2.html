DJI Dock 3 航线生成器 WPML / KMZ

校园巡检 · Matrice 4D / 4TD · Cloud API 航线文件
本工具在高德地图上规划点位。高德地图坐标为 GCJ-02，DJI WPML 固定要求 WGS84； 导出时会执行 GCJ-02 → WGS84 近似逆变换。正式飞行前请用 DJI / RTK 实测点核验坐标。
① 飞行器与任务
任务高度基准：relativeToStartPoint（相对起飞/航线起始点）。当前默认 70 m；这不是“任何地面位置都严格离地 70 m”。
返航高度由下方 Cloud API 回填；接口未返回有效值时，按 45 m 导出。
② Dock 3 / Cloud API 参考值
响应需含起飞参考点（longitude/latitude 或 lng/lat）和可选 rth_height。坐标必须是 WGS84；高度缺失时返航高度自动为 45 m。
